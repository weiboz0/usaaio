# Plan 021 — Round 2 Cross-modal Transformers and Advanced Vision

## Goal

Ship `book2:B2-021-cross-modal-transformers-vision` as a self-contained,
double-length Round 2 unit after B2-020.
It closes `vision-transformers`, `object-detection`, `unet`, and
`graph-neural-network-transformer-applications` in theory, implementation,
and model-training modalities without introducing external data, model hubs,
or GPU requirements.

## Branch and baseline

- Branch: `feature/plan-021-cross-modal-vision`.
- Baseline: `main` at the branch point.
- The only learner-facing book root changed by this plan is `book2/`.
  Book 1 material remains an imported prerequisite and must not be copied,
  retagged, or modified.

## Scope and curricular boundary

The canonical owner is the Book 2 roadmap row
`B2-021-cross-modal-transformers-vision`.
It follows B2-020 and relies on its inherited C7 CNN and B2-019 Transformer
mechanics; it does not re-teach convolution, attention derivation,
tokenization, or language pretraining.

Every input image, graph, target, split, seed, expected probe, and trained
state is literal or generated by committed source code.
All training is CPU-only, fixed-seed, and completes in a fresh solution
notebook within 20 seconds.
No web download, torchvision dataset, pretrained model, opaque checkpoint,
or student data is allowed.

### Owned concepts

B2-021 owns exactly these four Book 2 concepts:

1. `vision-transformer` — Session 1.
2. `object-detection` — Session 2.
3. `unet` — Session 3.
4. `graph-neural-network-transformer-applications` — Session 4.

The unit also uses the already taught concepts `patch-embedding`,
`attention-mask`, `multi-head-attention`, `transformer-block`, and qualified
Book 1 CNN/training concepts through B2-020's prerequisite closure.

### Five-session teaching spine

| Session | File | Required teaching surface |
|---:|---|---|
| 1 | `01-image-patches-and-vision-transformers.ipynb` | image `(B,C,H,W)` to non-overlapping patch tokens, linear patch projection, class token, learned positions, ViT shape ledger, and tiny synthetic image classification |
| 2 | `02-detection-grids-and-set-prediction.ipynb` | box coordinate convention, IoU derivation, grid/cell target encoding, objectness/class/box losses, thresholding, NMS, and a tiny detection training/evaluation trace |
| 3 | `03-unet-segmentation-and-skip-connections.ipynb` | encoder/decoder resolution ledger, skip concatenation, U-Net output alignment, pixel masks, Dice/IoU metrics, and synthetic segmentation training |
| 4 | `04-graphs-cross-modal-tokens-and-transformers.ipynb` | adjacency/message aggregation, graph tokens, cross-modal image/graph attention roles, query/key/value ownership, and a tiny graph-token classifier |
| 5 | `05-vision-system-design-and-audit.ipynb` | choose classify/detect/segment/graph task framing, output heads/losses/metrics, split/leakage audits, and an end-to-end architecture review |

Each session has 6–10 substantive sections, at least two checkpoints per
section with collected answers, common pitfalls, exam connections, and one
forward-only deeper topic.
Session 1 contains a worked patchification-to-logit shape example.
Session 3 contains a worked skip-concatenation and Dice calculation.
