# Using This Answer Key

This book gives worked solutions to the Set A practice problems of every unit.
Set A is the fundamentals set: one idea at a time, at introductory or core difficulty.
The solutions are grouped by unit, in the same order as the units of the Student Book, and each one follows the title of the problem it solves.

## Try first, compare after

Work each problem in its practice notebook before you open this book.
Run your notebook from the top with the seed it gives you, and check every identifier, shape, and dtype the statement asks for.
If you get stuck, read just enough of the solution to see your next step, close the book, and finish the problem yourself.
When you are done, compare your work with the solution and ask why any difference matters.
Reading a solution teaches you how it looks; writing your own is what builds the skill.

## A different solution can be right

Many problems have more than one correct solution.
A coding answer is correct when it keeps every required identifier and signature, produces the requested values and shapes, uses no banned API, and respects the stated data roles.
A derivation is correct when every step is justified, even if your steps come in a different order.
A numeric answer must still be in the exact form the problem asks for.

## Reading a solution

Most solutions open by repeating the problem's header: its set, type, difficulty, concepts, and compute policy.
A multiple-choice or short-answer solution works the answer step by step, then names it, and often explains which mistake leads to each wrong option.
A coding solution shows the complete code that satisfies the statement.
Every solution includes a short section headed **Answer check**: a cell of `assert` lines that compare the results with the expected values, often within a stated tolerance.
If your notebook passes the same checks, your answer agrees with the solution.

This book prints code without its output.
Every solution runs from top to bottom on a CPU with a fixed seed, so when you run it yourself you see the values the solution produced.
Small differences in the last digits can come from a different CPU or library version; the tolerances in the answer checks allow for them.

## Why only Set A

Set B, the exam register, and Set C, integration and challenge, have no answers outside the Teacher's Edition.
They are where you show what you can do without help, and your teacher may use them for homework or quizzes.
Use the Set A solutions to learn a method, then prove you can use it on Sets B and C.

Most checkpoint answers are printed in the notebooks themselves, under **Collected answers**, so they are not repeated here.
