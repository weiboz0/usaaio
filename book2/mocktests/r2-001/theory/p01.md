## Shared setup (used by every part of Problem 1)

**Tokens.** The vocabulary has $V=24$ token IDs, $0,1,\dots,23$.
A corpus row is a sequence of $13$ token IDs $t_0,t_1,\dots,t_{12}$.

**The model $\mathcal M$.** A decoder-only (causal) Transformer language model with

- model width $d=32$, $h=4$ attention heads (head width $d_h=d/h=8$), $L=2$ Transformer blocks, feed-forward width $d_{ff}=64$, and maximum context length $n=12$;
- a learned token-embedding table `nn.Embedding(24, 32)` (no padding row, no weight tying);
- a fixed sinusoidal positional table $\mathrm{PE}\in\mathbb R^{n\times d}$ (defined below), added to the token embeddings; it is a constant buffer, not a trainable parameter;
- two **pre-norm** Transformer blocks, each computing, for an input $x$ of shape $(B,n,d)$,
  $$u=\mathrm{LN}_1(x),\quad y=x+\mathrm{MHA}(u),\quad v=\mathrm{LN}_2(y),\quad z=y+W_2\,\mathrm{ReLU}(W_1v+b_1)+b_2,$$
  where $\mathrm{LN}_1,\mathrm{LN}_2$ are `nn.LayerNorm(32)` (each with a learned scale and a learned shift of length $d$), $W_1,b_1$ come from `nn.Linear(32, 64)`, and $W_2,b_2$ from `nn.Linear(64, 32)`;
- a final `nn.LayerNorm(32)` followed by a vocabulary head `nn.Linear(32, 24)` (with bias) that maps each position to $24$ logits.

**Multi-head causal self-attention (MHA).** Four learned maps $W_Q,W_K,W_V,W_O\in\mathbb R^{d\times d}$, each with a bias vector in $\mathbb R^d$ (each is one `nn.Linear(32, 32)`).
For $u\in\mathbb R^{B\times n\times d}$ form $Q=uW_Q+b_Q$, $K=uW_K+b_K$, $V=uW_V+b_V$.
Head $r\in\{0,\dots,h-1\}$ uses feature columns $r d_h,\dots,(r+1)d_h-1$ of $Q$, $K$, $V$, giving $Q_r,K_r,V_r$ of shape $(B,n,d_h)$.
Its scores are $S_r=Q_rK_r^{\top}/\sqrt{d_h}$, shape $(B,n,n)$, where entry $(i,j)$ scores query position $i$ against key position $j$.
The **causal mask** allows entry $(i,j)$ exactly when $j\le i$; forbidden scores are replaced by $-\infty$ **before** the row-wise softmax, giving weights $A_r$.
The head output is $H_r=A_rV_r$; the four head outputs are concatenated along the feature axis (head $r$ again in columns $rd_h,\dots,(r+1)d_h-1$) to shape $(B,n,d)$ and multiplied by $W_O$ (plus $b_O$).

**Sinusoidal positions.** For zero-based position $p$ and $i=0,1,\dots,d/2-1$,
$$\mathrm{PE}[p,2i]=\sin\!\big(p\,\omega_i\big),\qquad \mathrm{PE}[p,2i+1]=\cos\!\big(p\,\omega_i\big),\qquad \omega_i=10000^{-2i/d}.$$

**Causal language-model training.** For a batch of token rows `tokens` of shape `(B, 13)`, the model reads `inputs = tokens[:, :-1]` and is scored against `targets = tokens[:, 1:]` (both `(B, 12)`).
The loss is the mean token cross-entropy, $-\frac1N\sum\ln p_{\mathcal M}(\text{target}\mid\text{visible prefix})$, over the $N$ scored target positions.

**Perplexity.** For a set of $N$ scored target positions with model probabilities $p_1,\dots,p_N$ assigned to the true targets,
$$\mathrm{PPL}=\exp\!\Big(-\frac1N\sum_{m=1}^{N}\ln p_m\Big),$$
the exponential of the mean token cross-entropy (natural logarithm).
A target position that holds the padding ID is **not** scored: it is excluded from both the sum and $N$.

**Cost conventions.** A *multiply-add* is one product term inside a dot product: computing $C=AB$ for $A\in\mathbb R^{a\times b}$, $B\in\mathbb R^{b\times c}$ costs $abc$ multiply-adds.
Bias additions, the softmax, the $1/\sqrt{d_h}$ scaling, masking, and LayerNorm are not counted.
Attention products are computed densely: all $n\times n$ score entries are computed, including the ones the mask later forbids.
