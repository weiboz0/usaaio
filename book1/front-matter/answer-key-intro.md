# Using This Answer Key

This book gives worked solutions to the Set A practice problems of every unit.
Set A is the fundamentals set: one idea at a time, at introductory or core difficulty.
The solutions are grouped by unit, in the same order as the units of the Student Book, and each one follows the title of the problem it solves.

## Try first, compare after

Work each problem in its practice notebook before you open this book.
Run your notebook from the top, check every name and shape the statement asks for, and fix what does not match.
If you get stuck, read just enough of the solution to see your next step, close the book, and finish the problem yourself.
When you are done, compare your work with the solution and ask why any difference matters.
Reading a solution teaches you how it looks; writing your own is what builds the skill.

## A different solution can be right

Many problems have more than one correct solution.
A coding answer is correct when it keeps every required name and signature, produces the requested values and shapes, and avoids every banned tool.
Your loop may be a vectorized expression in the solution, or the other way round; that is fine unless the statement bans one of them.
A derivation is correct when every step is justified, even if your steps come in a different order.
A numeric answer must still be in the exact normal form the problem asks for.

## Reading a solution

A multiple-choice solution names the correct option, explains why it is right, and often says what mistake leads to each wrong option.
Read the explanations of the wrong options too: they are a list of the traps the question was built to catch.

A coding solution shows the complete code.
Every solution, multiple choice included, has a short section headed **Answer check**.
It is a cell of `assert` lines that compare the results with the expected values, often within a stated tolerance.
If your code passes the same checks, your answer agrees with the solution.

This book prints code without its output.
Every solution notebook runs from top to bottom with a fixed seed, so when you run it yourself you see exactly the values the solution produced.

## Why only Set A

Set B, the exam register, and Set C, integration and challenge, have no answers outside the Teacher's Edition.
They are where you show what you can do without help, and your teacher may use them for homework or quizzes.
Use the Set A solutions to learn a method, then prove you can use it on Sets B and C.

The checkpoint and self-quiz answers are not in this book either.
They are in the notebooks themselves, and the full Student Book collects them in an appendix.
